# Question à poser à Aflokkat / 3W Academy — modalité "groupe" vs solo

> Brouillon d'email/message à envoyer avant de rédiger les livrables concernés.
> Objectif : lever le doute avant d'investir du temps sur des dossiers qui pourraient être invalidés par le jury.

---

## Constat

Le référentiel d'évaluation (RNCP niveau 7, Expert en informatique et système d'information, 3W Academy) précise pour chaque livrable une **modalité d'évaluation**. Sur les 10 livrables de mon parcours (blocs 1, 2, 3, 4A — option cybersécurité), 3 sont explicitement **individuels** et **6 à 7 sont notés "Évaluation réalisée en groupe de 3 personnes maximum"** :

| Livrable | Modalité officielle |
|---|---|
| 1.1 Dossier de veille | Individuel |
| 1.2 Cahier des charges fonctionnel | Groupe de 3 max |
| 1.3 Dossier d'analyse stratégique | Groupe de 3 max |
| 2.1 Cahier des charges techniques + note de cadrage | Groupe de 3 max |
| 2.3 Dossier de planification (+ bilan) | Groupe de 3 max |
| 2.4 Plan de changement | Groupe de 3 max |
| 3.1 Dossier de conception (UML) | Groupe de 3 max |
| 3.2 Application développée + dossier technique | Individuel |
| 4A.1 Dossier d'analyse des risques SI | Individuel |
| 4A.2 Simulation de hacking / pentest | Groupe de 3 max |

Le livrable 1.2 a déjà été produit en groupe de 3 dans le cadre du projet de formation Aflokkat — c'est cohérent avec le référentiel.

**Problème** : je poursuis mon support technique de certification (`restaurant-analytics`) en solo, sans groupe constitué. Je n'ai pas de camarades disponibles pour reprendre une évaluation de groupe sur ce projet.

## Question à poser

1. Pour les livrables 1.3, 2.1, 2.3, 2.4, 3.1 et 4A.2 (marqués "groupe de 3 max") : est-il possible de les produire et les présenter **individuellement**, ou la modalité de groupe est-elle une exigence stricte du référentiel d'évaluation qui ne peut pas être contournée ?
2. Si la modalité de groupe est obligatoire : existe-t-il un groupe de candidats en cours de formation avec qui je pourrais me rattacher pour ces évaluations, même a posteriori ?
3. Le cas échéant, le contexte "solo dev / alternance" est-il un motif recevable pour une adaptation des modalités (indépendamment du dispositif handicap prévu à l'article L6113-1) ?

## En attendant la réponse

Je continue de produire les 3 livrables individuels du référentiel (1.1 dossier de veille, 3.2 dossier technique, 4A.1 analyse des risques SI), qui ne sont pas concernés par cette question.
